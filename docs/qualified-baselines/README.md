# Qualified smartphone performance references

These files freeze source-controlled numeric references without shipping the private physical images, secret key, payload files, or raw diagnostic logs.

- `build76-phone-performance.tsv` — historical Build76 two-run reference.
- `build84-phone-performance.tsv` — previous qualified Build84 two-run command-matrix reference.
- `build90-phone-performance.tsv` — current qualified Build90 evidence: all three full semantic physical runs are retained, including the host-degraded run, plus the contemporaneous Build91 paired means used for promotion.
- `build91-build84-build90-paired.tsv` — exact authoritative rows from the completed Build91 AB/BA paired physical profile.

Build90 promotion is based on semantic equivalence, race-clean public qualification scheduling, three independent full 9/9 semantic physical gates, and the contemporaneous paired Build84/Build90 timing evidence. Cross-day absolute timing was not cherry-picked.
